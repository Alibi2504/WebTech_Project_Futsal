# AITU FUTSAL WEBSITE

The website presents information about the AITU futsal club, its team, leagues, events, gallery, and registration/contact information.

## Our Team

- Yerassyl Bakhtybay
- Shyngyskhan Zharylgassyn
- Alibi Ramazan

## Website Pages

The website contains 6 HTML pages:

- `index.html` — Home
- `team.html` — Our Team
- `leagues.html` — Gold & Silver Leagues
- `events.html` — Events & University Team
- `gallery.html` — Gallery
- `join.html` — Join Us

## Technologies

We use:

- HTML5
- CSS3
- CSS Media Queries
- Bootstrap 5.3.3
- Bootstrap Grid
- Bootstrap Navbar
- Bootstrap Buttons
- Bootstrap Carousel
- Bootstrap Cards
- Bootstrap Forms

#Responsive Design

The website is responsive and adapts to:
Mobile devices
Tablets
Desktop screens

CSS Media Queries are used for responsive typography and card layouts. Bootstrap Grid is used for responsive page sections.

Bootstrap Components

The project uses Bootstrap components such as:

Responsive Navbar with a mobile hamburger menu
Responsive Grid
Buttons
Cards
Carousel
Responsive Form
Player Image Mapping
#Live Website:

The website is published using GitHub Pages.

Open the website in a browser using the GitHub Pages link.
